# Import / migration guide (in-app wizard + scripted bulk path; both verified)
1. **Stage** — `python3 migration/extract.py <Excel-root> migration/staging.sqlite` (lossless: every cell + interpreted blocks/variants). Then `derive_findings.py`.
2. **Verify** (all must pass; any parser change must re-run them): `verify_staging.py` (0 unexplained cells), `verify_against_source.py <root>` (every record re-read from the original files), `verify_coverage.py` (no orphaned data cell).
3. **Review findings** — `docs/registers/anomalies.csv`, `docs/source-data-audit.md`, `docs/snapshot-reconciliation.md`; client decisions are recorded in `docs/open-questions.md`.
4. **Rehearse** — `python3 migration/load_rehearsal.py` imports into a throwaway PostgreSQL and writes `docs/reconciliation-report.md` (source vs imported counts, value-for-value comparison, ledger-vs-balance check, duplicate handling, legacy-vs-app suggested orders). Held duplicates are never merged; blanks stay NULL; suspect stock is `unverified`.
5. **Approve** — decisions are recorded in the app's Data review queue (audited).
6. **Production import (implemented, verified on an empty database):** use **Import Excel** (upload → preview → choose folder → approve) per workbook, or `migration/bulk_import_via_api.py` to recreate the whole tree. The wizard stages (nothing live changes), rejects a byte-identical file already imported (no doubling), never overwrites existing positions, queues every finding for review, imports blanks as *not recorded* (never 0) and stock sheets identical to targets as *unverified*, and can be rolled back while nothing else has touched the imported items. The TypeScript extractor is proven equal to the Python reference (`web/tests/unit/parity.test.ts`: 7,931 records and 479 findings, 0 differences). **Still required before go-live: the client's answers to `docs/open-questions.md` and sign-off of the reconciliation on real data.**
7. **After go-live**, further data arrives only through receipts/issues/count sessions/targets (Excel count and target sheets are supported); there is no recurring bulk workbook import yet.
